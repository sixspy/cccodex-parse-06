## 去重落档

解析结果每条带去重钥匙，落档前先在**钥匙页**（`/dedup/policy/`）定处置：

- 只许定一种处置写进策略，写完当天不许换：`跳过并计数` 或 `整批失败并退回读盘前快照`。
- 落档携带的处理法与钥匙策略不一致 → 拦回「去重处理写歪了」。
- 钥匙字段空着禁止落档；读盘未收尾禁止开去重落档。
- 同一批（同一读盘代次）落档两人争抢只成一笔，只记先到。
- 去重在后台线程做；**落档列表**（`/dedup/batches/`）并排读出跳过条数、撞钥条数、处置名，**撞钥详情**（`/dedup/batches/<id>/`）可读撞钥样例与后到失败摘要。

Mock 造数规则（确定性）：每批每第 7 条撞首条钥匙；`index_json` 第 3 条钥匙为空（用于空钥匙拦截演示）。
